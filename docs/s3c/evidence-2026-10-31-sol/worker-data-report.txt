2. **BGE versus PJM geography.** The demand path is **PJM balancing-authority demand**, not BGE demand. It is paired with BWI station temperatures. The mart explicitly references the PJM and BWI models, and the loader filters EIA rows to respondent `PJM`, type `D`.    BWI is a single-location weather proxy for a regional load target. That is a modeling limitation, but I found no evidence that BGE load was accidentally substituted for PJM in this probe. Its effect on forecast error remains unmeasured. The architecture specifies PJM-wide forecasts and describes BGE as trailing background data. [Architecture](C:/Users/ajbig/Documents/grid-project/docs/architecture-s3-s7.md:13).

3. **Alerts / receipts dependency.** Alerts are optional date-keyed annotations. They do not change peak MW, peak hour, or level, and neither the historical probe nor the numerical model requires an external receipt store to score. The `ForecastReceipt` returned by `forecast` is an in-memory record of gates and fallbacks. [stress.py](C:/Users/ajbig/Documents/grid-project/src/grid_pipeline/stress.py:189), [model.py](C:/Users/ajbig/Documents/grid-project/src/grid_pipeline/model.py:61), [alert test](C:/Users/ajbig/Documents/grid-project/tests/test_stress_rulings.py:247).

   The receipt’s `verified_at_issuance` label deserves care: the model sets it after checking the supplied target-weather timestamp. The diagnostic supplies **settled mart temperatures** but pairs them with the first-recorded observation’s timestamp. If those values differ, that timestamp does not prove availability of the supplied settled values. Freshness is also forced to `True` in the probe. [Diagnostic](C:/Users/ajbig/Documents/grid-project/scripts/diagnose_s3c.py:62), [forecast gate](C:/Users/ajbig/Documents/grid-project/src/grid_pipeline/stress.py:221).

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'

@'
from collections import Counter, defaultdict
from dataclasses import replace
from datetime import date, datetime, timedelta, timezone
from pathlib import Path
from zoneinfo import ZoneInfo
import json
from grid_pipeline.model import HistoryDay, Features
from grid_pipeline.stress import forecast, parse_definition, DefinitionGap

p = Path('data')
ny = ZoneInfo('America/New_York')
coverage = json.loads(Path(
    r'C:\Users\ajbig\AppData\Local\Temp\grid-s3c-20261030\history-complete\coverage.json'
).read_text())
gaps = {date.fromisoformat(x['local_date']): x for x in coverage['gaps']}
loads, temperatures = defaultdict(list), {}

for f in (p / 's1-live/raw/eia').glob('*.json'):
    for x in json.loads(f.read_text(encoding='utf8'))['response']['data']:
        if x.get('respondent') == 'PJM' and x.get('type') == 'D':
            t = datetime.strptime(x['period'], '%Y-%m-%dT%H').replace(tzinfo=timezone.utc)
            d = (t - timedelta(microseconds=1)).astimezone(ny).date()
            loads[d].append((t, x['value']))

for f in (p / 's3a-verification/raw/ncei').glob('*.json'):
    for x in json.loads(f.read_text(encoding='utf8')):
        if x.get('STATION') == 'USW00093721':
            temperatures[date.fromisoformat(x['DATE'])] = x

d = date.fromisoformat(coverage['coverage'][0]['first_date'])
end = date.fromisoformat(coverage['coverage'][0]['last_date'])
history = []
while d <= end:
    if d in gaps:
        g = gaps[d]
        peak, hour, high, low, complete = (
            g['peak_mw'], g['peak_hour_ending'], g['tmax_f'],
            g['tmin_f'], g['complete']
        )
    else:
        t, v = min(loads[d], key=lambda x: (-float(x[1]), x[0]))
        peak, hour = float(v), t.astimezone(ny).hour or 24
        high, low, complete = (
            float(temperatures[d]['TMAX']), float(temperatures[d]['TMIN']), True
        )
    history.append(HistoryDay(d, peak, hour, high, low, complete,
                              d in loads, d in temperatures))
    d += timedelta(days=1)

cohort = [h for h in history if 2019 <= h.date.year <= 2026
          and h.complete and h.high_f is not None and h.morning_low_f is not None]
definition = parse_definition(Path('ledger/definitions/stress-index-v1.toml').read_bytes())
unattested = [replace(h, load_first_recorded=None, temperature_first_recorded=None)
              for h in history]

for name, pool in [('conditional', history), ('unattested', unattested)]:
    counts, candidates = Counter(), []
    for h in cohort:
        try:
            f = forecast(Features(h.date, h.high_f, h.morning_low_f,
                                  tuple(pool), True, True), definition)
            counts[f.level if f.status == 'SCORED' else f.no_call_reason] += 1
            if f.status == 'SCORED':
                candidates.append(f.receipt.sample_sizes['analog_candidates'])
        except DefinitionGap:
            counts['calendar_definition_gap'] += 1
    print(name, dict(counts), 'scored candidate range',
          (min(candidates), max(candidates)) if candidates else None)
```
